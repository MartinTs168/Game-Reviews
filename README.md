## 1. Project description

Game Reviews is a website for rating and reviewing video games.

### Main functionalities

- Ability to view every game for all users, including non-registered users.

- Ability to filter games by tags and name.

- Registered users can leave ratings and reviews on games, and also edit their profiles.

- Administrators can manipulate games, reviews, ratings, tags and users through the django admin panel.

## 2. Technologies

- The backend is written in **Python** and **Djnago** with the **MVT** pattern.

- The frontend is built with: **HTML**, **CSS**, **JavaScript**
